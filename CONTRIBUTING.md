# Contributing

Frontspan is in Sprint 0. Please discuss changes in an issue before implementation. Accepted ADRs govern architecture; proposals are not commitments.

Use focused branches and pull requests targeting main. Include issue references, acceptance criteria, validation results and any unresolved risks. Do not merge your own agent-generated changes without maintainer review. Branch protection and CI requirements are planned, not yet enforced.

Use synthetic API examples and avoid proprietary or personal information. Report security concerns privately to the maintainers rather than publishing exploitation details in issues. Dependency and copied-code licensing must be reviewed; follow the Apache-2.0 license and preserve required notices.

See [AGENTS.md](AGENTS.md) and [Sprint 0](docs/planning/SPRINT-00.md).
